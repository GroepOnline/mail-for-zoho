# Support — Mail for Zoho

Mail for Zoho is an unofficial open-source integration maintained by OnlineChefGroep.

## General questions and bugs

Use the public GitHub issue tracker after the clean public repository is created. Include the plugin version, client surface, operating system when relevant, and a redacted description of the failing tool or workflow.

## Security and privacy reports

Send suspected credential exposure, mailbox-data exposure or security vulnerabilities privately to `chefadmin@chefgroep.online`.

Never include any of the following in a public issue:

- the generated Zoho MCP URL;
- OAuth tokens or cookies;
- mailbox account IDs;
- message bodies, attachments or personal data;
- screenshots containing authentication material.

## Provider-specific problems

Authorization failures, Zoho account permissions and availability of the official MCP service may require Zoho support. ChatGPT plan, workspace, app availability and submission-review problems may require OpenAI support. This project cannot change either provider's account controls.
